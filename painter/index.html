How the earlier run was adapted

For the archived supervision-v5 study, each P=2 episode was evaluated as two native P=1 forwards, then the two predictions were averaged before scoring. The bench_v2 result above does not use this adapter.

Real

True demonstrations

Two demonstrations drawn from the query's source and coded with the query target.

Scrambled

Grey

Content removed

A low-information negative control for visual-prompt use.
