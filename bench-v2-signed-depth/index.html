Depth scoring: negative scales allowed

The selected model recipes are unchanged. This evaluation fits inverse-depth scale and shift using each query’s answer key, including a negative scale when the predicted direction is reversed. It removes only the old rule that replaced a negative fit with a constant.

This changes the evaluation rule. It is not target-free postprocessing or a new model result. No extra metadata enters model inference. It measures depth shape after allowing a direction flip, so it no longer tests whether the model learned the requested near/far direction.

All 187 original query means reproduce from 306 saved predictions, including all eight Analogist candidates per query. The new scorer matches the frozen function with only the negative-scale reset removed, and an independent covariance fit. Flat outputs still receive a constant fit. Missing predictions, crop, valid-depth range, minimum inverse depth and coverage penalties are unchanged. Painter and VICT retain their native-depth decoding correction.
