What you’re looking at.

All of your selections

Ten queries from each of the 26 datasets in qual_picks_v1_inputs. Seven completed baselines are included: GenLV, IMProv, LVM, Painter, Prompt Diffusion, VisualCloze, and Analogist.

The demos actually used

GenLV, IMProv, LVM, Painter, Prompt Diffusion, and Analogist each use one context pair per query. VisualCloze uses two. These run-specific pairs are shown on every model card. The original eight reference pairs remain available under each dataset heading.

Original images

Query inputs, predictions, and matching targets are unchanged saved PNGs. Demo tiles were recovered from the original benchmark packs and checked against the saved episode hashes. The images are the 256 × 256 benchmark tiles.

A qualitative selection

These 260 images are a selected subset of the completed Bench v2 test campaign, using supervision v6. Visit the full test results for quantitative comparisons and their qualifications.
