PROTOCOL AND COVERAGE

How to read these results

Same frozen test queries

The campaign contains 17,511 queries across 26 Bench v2 test packs, rendered with supervision v6. Pack identities and query keys are checked across all six models. Dataset names ending in “val” are the underlying source split names; these packs belong to the frozen Bench v2 test suite.

Task means and dataset means

Every displayed score is the arithmetic mean of the stored per-query primary metric. A task mean weights its two datasets by query count. Edge OIS, saliency max-Fβ, segmentation and other metrics here are per-query means, not newly pooled dataset statistics. The CSVs preserve full numeric precision.

Depth and edge qualifications

Depth uses the signed-scale alignment contract: the target determines alignment, including depth direction. Painter retains native-depth decoding. IMProv retains the validation-selected square-root edge postprocessing experiment. These changes belong to the selected evaluation recipe.

Controls and numerical scope

The copy-input control is scored for every query alongside each model. “Improvement” means copy minus model for lower-is-better metrics and model minus copy for higher-is-better metrics. Positive values are improvements. Completion does not establish cross-hardware or CUDA numerical parity.

Verification and source identities

Each completed model has a TEST_COMPLETE_VERIFIED receipt. This export verifies receipt-bound ledger hashes, authoritative score manifests, score-file hashes, pack identities, query coverage and finite primary scores. Original inference artifacts are unchanged.
