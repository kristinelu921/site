INSTANCE SEGMENTATION / 17 FROZEN QUERIES / THREE CONTRASTS

Does the native mask recipe help?

The released instance setup uses 560-pixel tiles and position-based mask colors. We compare its complete recipe against a generic 560-pixel control, then compare both with the existing 448-pixel CPU result.

Verified: 2026-10-31T06:03:55.420268+00:00

This is a fixed class-agnostic adaptation to the NYU benchmark. It uses only the supplied demonstration masks and query images. The frozen benchmark scorer is unchanged; these are not the paper’s COCO AP or panoptic results. No query labels or test-score tuning select the recipe.

The native recipe does not salvage this category on these 17 queries. Compared with the generic 448-pixel CPU condition, mean PQ falls from 0.049618 to 0.029679 (40.2% lower): 3 queries improve, 8 worsen and 6 tie. Resolution alone lowers the mean by 22.6%; the native mask recipe at the same resolution lowers it by 22.7%. The original results and every regression remain available.

PQ is higher-is-better. Positive changes mean improvement; negative changes mean regression. Relative changes can look large near zero, so inspect the absolute change too. Zero-baseline relative percentages are undefined. Scores are rounded here; downloads retain full precision.

All 17 queries are retained in every comparison. Gains and losses are each divided by 17, so their sum equals the mean change. Every copy control matches exactly across the three conditions.

The two new inference arms took 7.47 minutes on CPU. This does not establish TPU speed or numerical parity.

Recipe and scope

Fixed17P1 instance episodes on CPUFP32. Native560: centroid-position demo colors, released BICUBIC target, distance19 class-agnostic masks, GaussianNMSsigma2/top100 and released panoptic disjoint merge(score0.55,overlap0.5), semantic stuff disabled. No query metadata. Generic560 keeps frozen RGB demo target and NEAREST target interpolation. Native task recipe is a Bench adaptation, not COCO paper replication.

The adapter changes the instance-segmentation route only. The other 12 categories were not rerun by this experiment; their existing results remain separate. There is no mixed best-recipe aggregate.

  • Native support geometry derives from resized256RGBmasks, not full-resolution COCOannotations.
  • Class-agnostic NYU evaluation with released mask-overlap merge, not full COCOsemantic-plus-instance AP/PQ.
  • CPUqualification establishes no TPU precision, sharding or runtime claim.
