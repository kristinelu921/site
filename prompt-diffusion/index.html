04 / EVALUATION CONTRACT

How this run was adapted

Prompt Diffusion is natively single-prompt. Each P=2 episode is evaluated as two native P=1 forwards, then the two predictions are averaged before scoring.

Real

True demonstrations

Two demonstrations drawn from the query's source and coded with the query target.

Scrambled

Broken pairing

Demonstration relationships are disrupted; palette outputs use the corrected control.

Grey

Content removed

A low-information negative control for visual-prompt use.

Oracle

Upper bound

A positive control that exposes target structure.
