04 / METHOD

How to read the comparison

Real

True demonstrations

The query is paired with demonstrations drawn from the same source and coded together for that episode.

Scrambled

Broken pairing

Demonstration relationships are disrupted. Palette outputs are re-coded under the corrected E26 control.

Grey

Content removed

A low-information negative control that checks whether the model is using the visual prompt.

Oracle

Upper-bound context

A positive control that exposes the target structure and tests whether the evaluation path can recover it.
