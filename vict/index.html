02 / TEST-TIME TRAINING

What happens per query

VICT adapts the encoder independently for each query, predicts once, then resets. Learned state never carries between queries.

Prompt

One demonstration

One labeled example from the query’s task and source forms the test-time training pair.

Optimize

60 updates

AdamW at 1e-6 updates the Painter encoder; the decoder remains frozen.

Predict

One output

The adapted model predicts the hidden-target query once, with bicubic output interpolation.

Reset

Fresh each query

Model weights and optimizer state reset before the next of the 221 episodes.

No random adaptation crops

Every adaptation step sees the same complete demonstration image pair, resized to 448 × 448. There is no random crop, flip, or other augmentation. “Single crop” in the official loader denotes this one full-image view.

Backend qualification

Inference used a PyTorch/XLA v5litepod-4 numerical port with bfloat16, activation checkpointing, and sync-free AdamW. The official data setup and pinned weights are preserved; official CUDA numerical parity is not established.
