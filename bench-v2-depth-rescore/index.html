OCTOBER 31 / SAVED PREDICTIONS / NATIVE DEPTH DECODING

Depth structure was being read in the wrong direction.

Painter and VICT now use their native depth interpretation before the existing inverse-depth scorer. The selected results rise from 0.439263 to 0.984478 and 0.964251 respectively.

No extra inference metadata. These results reuse exactly the same saved predictions and RGB demonstration inputs. No model was rerun, and no demonstration depth endpoints were supplied. The separate metadata-assisted Painter experiment is a different condition.

The previous generic decoder treated brighter pixels as closer. The released Painter and VICT depth decoders instead map brightness to depth, where brighter pixels are farther away. The old nonnegative alignment rejected that direction and returned a constant for all 17 queries. Converting the saved depth values to inverse depth removes that failure.

This is a versioned model-specific output correction, with the same δ₁ metric and the same frozen targets, crop, depth range, scale-and-shift alignment, invalid-pixel mask and penalty. The other 12 categories retain every original query score. One complete recipe still applies to each model column.

What was checked

All original scores replay exactly. Image and target checksums match the archived manifests and supervision-v6 pack. An independent alignment calculation reproduces every corrected δ₁. Known-depth and missing-prediction fixtures verify the decoder direction and retained invalid-pixel penalty.

The fixed conversion is 1 / (mean(RGB) / 255) on valid pixels. Exact-black pixels remain invalid. The conversion takes only the saved prediction and model family; it does not inspect query targets, choose a transform per query or fit an extra parameter. Ground-truth depth remains confined to the existing evaluation alignment and scoring.

Source conventions: Painter’s released depth decoder and VICT’s released depth decoder. Both scale decoded output intensity linearly to metric depth.

Scope: this correction interprets already-quantized 8-bit predictions; it does not recreate the authors’ full native-resolution inference or establish CPU/TPU parity. GenLV’s exploratory brightness reversal has not been promoted because its native convention remains unresolved. Surface-normal failures remain open.
